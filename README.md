# NYC Taxi Lakehouse Pipeline

End-to-end data pipeline on Databricks using the medallion architecture.

## Goal
Ingest NYC TLC taxi trip data, clean it, and model it into a star schema for analytics.

## Stack
Databricks (Free Edition), PySpark, Delta Lake, SQL, Workflows

## Architecture
Bronze (raw) -> Silver (cleaned) -> Gold (star schema) -> Dashboard

## Status
In progress.
